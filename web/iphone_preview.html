App not updating after code changes? The iframe loads index.html / main.dart.js. Re-run flutter build web or hot-restart flutter run -d web-server. If an old build sticks, use the buttons below or Chrome DevTools → Application → Clear site data (service worker cache).
Tip: flutter build web --pwa-strategy=none avoids a service worker so refreshes pick up new builds more easily.

Dev: flutter run -d web-server --web-hostname=localhost --web-port=8080 (if 8080 is busy, use another port, e.g. 9100)
Then open iPhone preview — must be the same host and port as flutter run so the iframe loads index.html from the same origin.

Static: flutter build web → serve build/web → iphone_preview.html
